# Clinic Diary

A simple app for a solo dentist to track missed calls, appointments, follow-ups and WhatsApp reminders (Hindi + English messages).

**Install on iPhone:** open the link in Safari → Share → Add to Home Screen.

Data is stored on the phone itself (pilot version). Use Settings → Copy backup regularly.

## Cloud and clinic line

Optional backend (Supabase) for login, online data, and automatic call tracking through an Exotel clinic line.
See [SETUP.md](SETUP.md).
